# Красные врата Гронека — 3D-игра по кампании «Жнец»

Одностраничная браузерная игра (Three.js r128 с cdnjs). Свободное исследование в реальном времени, пошаговый бой как в BG3, управление касаниями под телефон.
Опубликована как артефакт: https://claude.ai/artifact/P5ALdSJNd8BsSZu1wLSoWW (republish из этого файла: `игра/index.html`).

- Игра — отдельная адаптация: её исходы не меняют канон настольной кампании, если игрок не скажет иначе.
- Содержание глав берётся из `.gm/подземелья/` (тайное) — не пересказывать игроку вне игры.
- Сохранение — localStorage браузера (чекпоинт на входе в уровень).
