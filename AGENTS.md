# Кампания «Жнец» — вход для Codex

Этот репозиторий — общая кампания для Claude Code и Codex.

## Роль Codex: художник кампании

- По умолчанию Codex создаёт арты, портреты, иллюстрации сцен и страницы манги. Claude Code может вести игру и готовить задания для иллюстраций; Codex продолжает игру только по просьбе игрока.
- Для визуальных задач сначала прочитай `визуал/README.md`. Используй встроенную генерацию изображений и навык `imagegen`, если они доступны: результатом должны быть сами изображения, а не только промпты.
- Сохраняй облик персонажей по визуальной библии и доступным референсам. Манга — допустимый отдельный стиль; запреты anime/cartoon из старых фотореалистичных промптов к ней не относятся.
- Иллюстрирование сыгранного не меняет события кампании, ресурсы персонажа и игровое время. Не добавляй Шину реплики, которых игрок не произносил.

## Общие правила

- Сначала прочитай `CLAUDE.md`: это общая инструкция мастера. Перед продолжением игры прочитай перечисленные в ней файлы состояния и инструкции нужных ролей из `.claude/agents/`.
- Правила, журнал, персонаж, знания и тайны общие для обоих помощников. Не создавай отдельное сохранение для Codex и не начинай кампанию заново при смене помощника.
- Соблюдай разделение публичного и тайного из `CLAUDE.md`; содержимое `.gm/` не раскрывай игроку, в том числе в технических отчётах.
- Технические просьбы о GitHub, настройке и файлах выполняй вне игры: они не являются действиями Шина и не продвигают игровое время.
- Синхронизируй изменения по разделу «Сохранение» в `CLAUDE.md`. При передаче игры опирайся на файлы репозитория, а не на недоступную историю другого чата.
