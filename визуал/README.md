# Арты и манга кампании «Жнец»

Codex — художник кампании: создаёт изображения, сохраняет их в проект и показывает игроку. Claude Code может вести игру и готовить задания. Передача идёт через GitHub; сохранение задания не запускает другой чат автоматически.

## Источники и канон

Перед работой подтяни актуальный `main` по правилам `CLAUDE.md`. Прочитай нужную запись в `journal.md`, кадр из `кадры/`, описание персонажа и `.gm/визуал.md`. Визуальная библия служит внутренним справочником: в публичные промпты и картинки переноси только уже известные игроку особенности внешности и сцены, без тайн мастера.

Приоритет: текущие пожелания игрока → принятые игроком визуальные референсы → описания кампании. Шину 37 лет, внешне около 28. Первые изображения — пробы внешности; не объявляй их утверждённым каноном без выбора игрока. Одобренный референс указывай в описании следующих работ и передавай в генератор, когда инструмент это поддерживает. Не обещай идеальную идентичность лица между генерациями.

## Канон мира для картинок

- В мире нет христианства: никаких крестов, куполов и церквей с крестами. Храмы — Мелитэле (женская богиня-мать) или Ордена Очищающего Пламени (огонь).
- Медальон Шина — голова волка; символ Белого Солнца (солнце с лучами) принадлежит вальдарским жрецам, Шину его не рисовать.
- У Шина вертикальные кошачьи зрачки, смешанные восточноазиатско-европейские черты, пепельно-серые волосы.

## Два формата

- **Арт:** цветная иллюстрация, портрет, локация, чудовище или ключевой момент. По умолчанию мрачное кинематографичное фэнтези с холодной сдержанной палитрой. Сохраняй черты, экипировку и возраст персонажа.
- **Манга:** чёрно-белая тушь, штриховка и скринтоны; реалистичные пропорции, выразительная постановка. По умолчанию 3–5 панелей на вертикальной странице, чтение слева направо и сверху вниз. Старые ограничения `no anime`, `no illustration` и фотореалистичные настройки к этому формату не применять.

Манга адаптирует сыгранные события. До генерации запиши порядок панелей, персонажей, действие и точный текст. Реплики Шина бери только из слов игрока, зафиксированных в источнике; при их отсутствии делай немую сцену. Для русского текста проверяй буквы, порядок реплик и принадлежность пузырей. Не добавляй новых решений героя или событий ради эффектной композиции.

## Выпуск изображения

1. Создай задание в `кадры/NNN_<название>.md`: источник сцены, формат, статус, точный промпт, референсы и путь результата. Продолжай существующую нумерацию.
2. Используй встроенный генератор изображений и доступный навык `imagegen`. Не подменяй запрошенную картинку HTML, SVG или описанием. Если генерация недоступна, сообщи об этом; внешний платный API самовольно не подключай.
3. Посмотри полученную картинку: лицо и одежда, руки, снаряжение, соответствие сцене; для манги также порядок панелей и текст. Исправляй конкретную ошибку отдельной итерацией.
4. Скопируй результат в `арты/` или `манга/`. Версии сохраняй отдельно (`-v1`, `-v2`); не затирай старые изображения без просьбы. Не оставляй единственную копию в служебной папке генератора.
5. Обнови путь и статус в задании, покажи изображение в чате, сохрани изменения в GitHub по `CLAUDE.md`. Не записывай изображённое повторно в игровой журнал и не меняй состояние кампании.
