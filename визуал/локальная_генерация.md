# Локальная генерация манги на ПК игрока (инструкция для Claude Code)

ПК игрока: Windows, видеокарта **AMD RX 580 8 ГБ** (Polaris). CUDA и ROCm на ней не работают. Поэтому используем **stable-diffusion.cpp со сборкой Vulkan** — работает на любой видеокарте с Vulkan, Python и драйверы ИИ не нужны.

## Цель
Цветная манга по арке «Соляной склеп» по сценарию `кадры/017_соляной_склеп_манга/` (16 страниц).
Каждую **панель** генерируем отдельно **без текста**. Страницы собираем сами, русские баблы, подписи и SFX накладываем кодом: генераторы пишут кириллицу с ошибками.

## Шаги
1. **Движок.** Скачать последний релиз `leejet/stable-diffusion.cpp` (GitHub Releases), архив `*-bin-win-vulkan-x64.zip`, распаковать в `C:\sd\`. Проверить командой `sd.exe --help`.
2. **Модель.** Взять модель на базе SD 1.5: она влезает в 8 ГБ и считается быстро. Нужен аниме- или живописный стиль, лицензия должна позволять личное использование. Варианты: DreamShaper 8, Counterfeit-V3, MeinaMix. Скачать `.safetensors` с Hugging Face или Civitai в `C:\sd\models\`. SDXL на RX 580 работает медленно и может не влезть в память, поэтому только для пробы.
3. **Проба.** Одна панель 512×768, 25 шагов, `--cfg-scale 6`, сэмплер `euler_a`. Ожидаемое время: 20–60 с на RX 580. Если не хватает памяти, добавить `--vae-tiling`.
4. **Промпты панелей.** Взять из `кадры/017_соляной_склеп_манга/стрNN.md` раздел «Раскладка» и Character sheet из `00_план.md`. Для каждой панели собрать короткий английский промпт ≤ 75 токенов: стиль, затем персонаж, действие, свет. Тексты баблов в промпт **не включать**.
   - Негатив: `text, letters, watermark, signature, blurry, extra fingers, deformed hands, chibi, cartoon, cross, crucifix, church dome`.
   - Стиль: `painterly dark fantasy, adult animation, bold ink lineart, hand-painted textures, cinematic rim light, muted earthy palette`.
5. **Консистентность.** Фиксировать seed на персонажа. Облик описывать одинаково (`ash-grey hair, golden cat eyes with vertical slit pupils, East Asian–European features`). Если понадобится, обучить LoRA по 10–15 лучшим кадрам Шина. Это отдельный шаг, только с согласия игрока.
6. **Сборка страниц.** Python + Pillow (или HTML/canvas):
   - формат 2:3, рамки панелей по «Раскладке»;
   - баблы с текстом дословно из страницы, шрифт с кириллицей (например, Comic Neue или PT Sans Narrow);
   - порядок чтения слева направо.

   Результат: `манга/017-solyanoy-sklep-pNN.png` и читалка `манга/017/index.html`.
7. **Сохранение.** Коммит в `main` с автором `undertaker-68 <undertaker-68@users.noreply.github.com>`, затем push. Тяжёлые модели в репозиторий **не класть**.
