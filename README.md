# Жнец — соло-НРИ в духе «Ведьмака»

Кампания для Claude Code: ведьмак Школы Волка Шин Нодзен, попаданец с Земли, в мире призванных героев, Врат и Дикой Охоты.

## Как продолжить игру
1. Открой этот репозиторий в Claude Code (локально или в облачной сессии на claude.ai/code).
2. Напиши, например: «Продолжаем кампанию». Мастер прочитает `CLAUDE.md` и файлы состояния и продолжит с последней сцены (`journal.md`).

## Что где лежит
- `CLAUDE.md` — инструкция мастера: цикл хода, принципы, агенты.
- `settings.md` — настройки игры и требования игрока (формат, баланс, стиль).
- `rules.md` — правила (проверки без кубиков, бой, прокачка, Знаки, мутагены).
- `character.md` — лист Шина; `sheet/index.html` — красивая версия листа (артефакт).
- `journal.md` — хроника сессий.
- `codex/` — что Шин знает о мире.
- `кадры/` — кинематографичные промпты для генераторов изображений.
- `.claude/agents/` — агенты: world-sim (живой мир), npc-mind, quest-forge, image-director.
- `.gm/` — **тайны мастера, спойлеры.** Игроку лучше не открывать.
