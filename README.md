# Жнец — соло-НРИ в духе «Ведьмака»

Общая кампания для Claude Code и Codex: ведьмак Школы Волка Шин Нодзен, попаданец с Земли, в мире призванных героев, Врат и Дикой Охоты.

## Как продолжить игру
1. Открой этот репозиторий в Claude Code (локально или в облачной сессии на claude.ai/code) либо в Codex.
2. Напиши, например: «Подтяни последнее сохранение из GitHub и продолжаем кампанию». Мастер проверит синхронизацию, прочитает `CLAUDE.md` и файлы состояния и продолжит с последней сцены (`journal.md`).
3. Перед переходом к другому помощнику попроси: «Сохрани сцену и отправь изменения в GitHub». В другом помощнике повтори шаг 2. Одну игровую сцену веди в одном месте, чтобы не получить две разные версии событий.

Общий репозиторий: [undertaker-68/NRI](https://github.com/undertaker-68/NRI), ветка `main`. Связь между помощниками идёт через сохранённые файлы; переписка между чатами не переносится.

## Что где лежит
- `AGENTS.md` — вход для Codex, указывающий на общие инструкции ([формат в документации OpenAI](https://learn.chatgpt.com/docs/agent-configuration/agents-md)).
- `CLAUDE.md` — общая инструкция мастера: цикл хода, принципы, агенты, синхронизация.
- `settings.md` — настройки игры и требования игрока (формат, баланс, стиль).
- `rules.md` — правила (проверки без кубиков, бой, прокачка, Знаки, мутагены).
- `character.md` — лист Шина; `sheet/index.html` — красивая версия листа (артефакт).
- `journal.md` — хроника сессий.
- `codex/` — что Шин знает о мире.
- `кадры/` — кинематографичные промпты для генераторов изображений.
- `.claude/agents/` — агенты: world-sim (живой мир), npc-mind, quest-forge, image-director.
- `.gm/` — **тайны мастера, спойлеры.** Игроку лучше не открывать.
