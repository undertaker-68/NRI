Покажи игроку окно Системы. Источник — `character.md` и видимые игроку блоки (не раскрывать `.gm/`).

Формат: моноширинный блок в квадратных скобках, как окно Системы, по-русски, без воды:
```
[ СТАТУС · Шин Нодзен «Жнец» · Школа Волка ]
[ Ур. N · XP a/b · Ранг Системы F ]
[ HP a/b · Энергия a/b · Токсичность a/b · Адреналин a/3 ]
[ Сила · Ловкость · Выносливость · Разум · Воля · Обаяние ]
[ Задания: ... ]
[ Титулы: ... ]
```
Затем коротко: активные эффекты, важные предметы, отношения (числа из листа). Скрытые условия Системы показывай как `???`. Игру не продолжай.
